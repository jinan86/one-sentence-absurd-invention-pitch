Entry for the [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) competition on make.fun. The program writes a single sentence pitching a ridiculous invention that fixes a tiny everyday annoyance.

## The pitch

> The Charger Snake is a phone cable that slithers to the nearest outlet by itself when your battery hits 5%, hissing at anyone who dares step on it mid-rescue.

The tiny annoyance: a phone battery dying at 5% with no outlet in reach. The absurd invention: a phone cable that slithers to the nearest outlet on its own — and hisses at anyone who steps on it while it works.

## How to run

```sh
python3 main.py
```

This writes the pitch to `/output/entry.txt` — exactly one sentence, 158 characters, no trailing newline. Python 3.13, standard library only, no network. Running it twice produces byte-identical output.
